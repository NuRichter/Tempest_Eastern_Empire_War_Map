the canonical mapping lives in public/data/nation-flags.json, generated by the
build-time compiler from data-source/gazetteer.source.json.

Place each PNG at exactly this path, keeping the spaces in the file names.

"Various Western States" is a grouping marker on the supplied map, not a state.
It carries no flag and none is expected.

Run "npm run validate-assets" after adding the files. A missing required flag
fails the build and names the nation and the path it expected.
