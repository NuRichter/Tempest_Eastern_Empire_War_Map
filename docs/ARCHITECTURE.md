# Architecture

```
Sources of Truth/                 research authority (novels, maps, photocards, Step 1 workbook)
        │  read by humans and by the research agents; never edited by the build
        ▼
data-source/                      hand-maintained, reviewable sources
  campaign/                       events (with effects), forces, movements, casualties, stages …
  gazetteer.source.json           every position on the map, with its placement grade and basis
  territories.geo.source.json     region polygons traced from the Base Map (generated by a script)
  territory-control.source.json   each territory's role in the war, anchored to events
  characters.source.json          characters + photocard provenance
  terminology.source.json         canonical names, aliases, Japanese names
        │
        ▼  scripts/compile-data.ts   (deterministic: same sources → byte-identical output)
public/data/                      runtime dataset: checkpoints + sparse deltas, tracks, reference tables
        │
        ├─▶ scripts/validate-data.ts    identities, references, time order, quantities, casualty arithmetic,
        │                               dual-path replay, geometry
        ├─▶ scripts/validate-assets.ts  map styles, flags, photocards
        ├─▶ scripts/test-runtime.ts     engine tests on the compiled data
        ▼
src/                              Next.js 15 + React 19 + MapLibre GL 5 + Zustand 5
```

The browser never sees a spreadsheet or a source file. `prebuild` runs the compiler and both validators, so a build cannot ship an unchecked dataset.

## Offline tools (Python)

| Script | Produces | When to run |
|---|---|---|
| `scripts/cartography/extract_territories.py` | `data-source/territories.geo.source.json` | After changing `regions.config.json`, the theatre zones in the gazetteer, or the Base Map |
| `scripts/characters/build_photocards.py` | `public/assets/characters/*.jpg` | After changing `characters.source.json` |

Both need Python 3 with `numpy`, `opencv-python` and `Pillow`. Their outputs are committed, so building the site needs Node only.

## Runtime modules

| Path | Responsibility |
|---|---|
| `src/data/loader.ts` | Fetches the runtime files; `assembleDataset` builds derived indexes (shared with the tests) |
| `src/simulation/clock.ts` | One deterministic clock outside React; continuous frame position; 0.25×–48× |
| `src/simulation/resolver.ts` | Frame state from checkpoint + deltas; force snapshot and interpolated position; territory control with transition; strength history |
| `src/simulation/store.ts` | Zustand store: data, frame, selection, filters, camera requests, navigation actions (`jumpTo*`) |
| `src/state/preferences.ts` | Persisted reader preferences (map style, layers, opacities, scales, motion) with safe storage |
| `src/map/MapView.tsx` | MapLibre: Base/Myth rasters, territory and operational-area layers, projection, camera requests |
| `src/map/overlay/*` | One canvas for everything that moves with the clock; layer modules draw labels, routes, forces, battles, events, portraits; hit-testing and tooltips |
| `src/components/*` | Shell, rail (layers, filters, feed, story), situation & dossiers, timeline, palette, legend, cinematic |
| `src/lib/*` | Coordinates, palette, taxonomy (shared vocabulary), search, formatting |

## Rendering loop

React re-renders only when the **integer** frame changes (10 simulated minutes). The overlay canvas repaints on demand — when the clock moves, the camera moves, a preference changes, or a battle is live — and reads the **continuous** clock position, so movement interpolates smoothly between keyframes without React in the loop. MapLibre layers (territories, operational areas) are updated with `setData` once per integer frame; with 20 territories and 5 areas that is cheap.

## Frame / delta model

Every 144 frames (one simulated day) a full checkpoint is stored; between them only changed fields are stored as deltas. Seeking costs one checkpoint plus at most one day of deltas. The validator replays every frame twice — sequentially and by seeking — and fails if the two disagree, so scrubbing always equals playing.

## Determinism

No randomness, no wall-clock-dependent state, no build timestamps. Formation fan-outs are ordered by id. Given the same dataset, frame, filters and projection, the same picture is drawn.
